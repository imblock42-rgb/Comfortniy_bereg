# Комфортный Берег

Статический сайт гостиничного комплекса «Комфортный Берег». На странице представлены краткое описание комплекса, примеры номеров и ссылки для навигации по разделам.

## Запуск

Сборка и установка зависимостей не требуются. Откройте `index.html` в браузере или запустите любой локальный статический веб-сервер из корня проекта.

## Структура проекта

- `index.html` — разметка страницы.
- `style.css` — оформление и адаптивная сетка.
- `script.js` — клиентский JavaScript (сейчас файл пуст).
- `assets/` — папка для изображений и других статических материалов.

Сайт является прототипом: бронирование, форма обратной связи и серверная часть не реализованы.
