# Комфортный Берег (CozyShore)

Статический прототип сервиса посуточной аренды жилья в Абхазии — аналог Суточно.ру, но с фокусом на побережье Абхазии (Гагра, Пицунда, Новый Афон, Сухум).

Страница содержит: поиск по направлению/датам/гостям с клиентской фильтрацией, каталог объектов размещения, блок популярных направлений, объяснение «как это работает» и форму заявки на бронирование/сдачу жилья.

## Запуск

Сборка не требуется для просмотра: откройте `index.html` в браузере или запустите любой локальный статический веб-сервер из корня проекта (`index.html` подключает JS как ES-модуль, поэтому через `file://` часть браузеров блокирует импорты — лучше через `http://localhost`).

Для разработки (линт/тайпчек/тесты) нужен Node.js 20+:

```bash
npm ci
npm run lint       # eslint + stylelint + html-validate
npm run typecheck  # tsc --checkJs по src/*.js
npm run test       # vitest
npm run ci         # всё вместе, как в CI
```

## Структура проекта

- `index.html` — разметка страницы.
- `style.css` — оформление, палитра, адаптивная сетка.
- `src/` — клиентский JS как ES-модули: `dates.js`/`catalog.js` — чистые функции, `nav.js`/`search.js`/`booking.js` — привязка к DOM, `main.js` — точка входа.
- `test/` — модульные и DOM-тесты (vitest + jsdom) на модули из `src/`.
- `assets/` — папка для будущих фотографий объектов (сейчас используются авторские SVG-иллюстрации вместо фотографий).
- `.github/workflows/ci.yml` — CI: lint, typecheck, тесты на каждый push/PR в `main`.

Сайт является прототипом: реальное бронирование, оплата и серверная часть не реализованы — форма заявки ничего никуда не отправляет и только показывает подтверждение в интерфейсе.
